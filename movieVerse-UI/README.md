# 🍿 MovieVerse UI (Frontend)

React-based frontend for **MovieVerse** — a movie ticket booking application.

## 🚀 Features

- User registration and login with secure authentication
- Browse movies, theatres, shows, and timings
- Seat selection with real-time locking mechanism
- Toast notifications and form validation
- Axios-based API communication with backend

## 🖥️ Tech Stack

- React.js (CRA)
- React Router DOM
- Bootstrap + Tailwind CSS
- Axios
- Formik & Yup
- React Toastify
- UUID
- JS-Cookie

## 🔧 Environment Variables

```env
# MovieVerse Service API
REACT_APP_MOVIEVERSE_SVC_API_BASE_URL=https://your-backend-url.onrender.com

# Optional API keys if any
REACT_APP_API_KEY=your_api_key
REACT_APP_NOT_SECRET_CODE=your_other_key
```
## 💻 Run Locally
- cd movieVerse-UI
- npm install
- npm start
